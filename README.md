TabbyCat is a text-based tab program designed to allow guitarists using ANY tuning or fretting scheme to be able to notate their songs and practice along with them with as little friction as possible.

It's basically written like an old school tracker and operates on soundfonts. I personally use it to write down music for my own musical projects. As a DIY xenharmonic luthier in a greater network of other DIY xenharmonic luthiers though, I realized this very particular tool space was not well represented in the software world. 

Practicing some rapid fire Scruggs-style banjo licks? Sure, you can do it.

Writing out synchronized drum/bass/guitar tabs for your garage band? TabbyCat's got you.

Composing a microtonal etude for a 41-TET Kite guitar that traverses the Toastedosma [0 -6 3 1 1 -1⟩ in 13-limit JI space? Hell yeah! And yes, I actually wrote TabbyCat so it would support this.

Wanting to make a single voice staff that isn't actually a stringed instrument that just lets you type out diatonic note names and numbers so you can write out a vocal melody? Lol, not really a tab, but still doable!

String harmonics? Check!

I haven't figured out tuplets or slides or bends. I have some ideas on how they'd be implemented though. If someone has an idea feel free to suggest something.

This isn't necessarily a one-stop shop for everything, but hopefully it's of enough use to enough people that sharing it makes the greater world of 'lute-family players' happy :)
