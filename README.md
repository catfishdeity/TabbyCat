TabbyCat is a text-based tab program designed to allow guitarists using ANY tuning or fretting scheme to be able to notate their songs and practice along with them with as little friction as possible.

It's basically written like an old school tracker and operates on soundfonts. I personally use it to write down music for my own musical projects, but as a DIY xenharmonic luthier in a greater network of other DIY xenharmonic luthiers, I realized this very particular tool space was...not really represented!

Also it supports string harmonics! Just type "H[\d]" where [\d] is the integer partial of the string harmonic! Piece of cake! Every string is polyphonic and independently tuned so you can kind of do whatever. If you wanted to transcribe some old no wave funky art school purposefully detuned music, this should do it. 

Regular guitar? You got it!
5 string bass guitar? You got it (and you've got good taste in bass)
8 string baritone djenty thing? Sure, don't forget your high gain harmonics!
41 TET kite guitar tuned in down major thirds starting at C2 with seven strings with every other fret skipped except for some in-between frets placed after the first, third, and fourth frets? Yeah sure, actually that's the default preset cause that's my guitar and it rocks.

I'm more than happy to hear input on what this could use! I developed it to fill a void and aim for it to be useful.
